# THE CHEZZ 🎀♟️

A cozy, offline chess game with a soft pink coquette style.

## About

THE CHEZZ is a Python desktop chess game where you can play locally with a friend or challenge the computer. It combines a pink gingham look with classic chess pieces and chess rules.


## Features

- Two-player local chess
- Play against the computer at Easy, Medium, or Hard difficulty
- Legal moves, selection highlights, and check detection
- Pink themed checkmate and game result screens
- Designed to play offline

## Built with

- Python
- Pygame CE
- python-chess
